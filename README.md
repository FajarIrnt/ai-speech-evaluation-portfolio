# AI-Generated Speech Evaluation

## Project Overview

This project compares two self-generated text-to-speech (TTS) audio samples using the same English text. The goal is to evaluate speech quality, naturalness, pronunciation, and contextual appropriateness.

Both samples were generated specifically for this personal portfolio project. No confidential company materials or internal task recordings were used.

## Test Text

> Good morning! Thank you for joining today's meeting. I'll explain the three main points, then we can discuss the next steps together.

## Evaluation Method

Both audio samples were evaluated using the same criteria and a 1–5 scoring scale.

| Evaluation Criterion | What Was Assessed |
|---|---|
| Audio Quality | Clarity and overall audio quality |
| Naturalness | Natural-sounding speech and intonation |
| Pronunciation | Clarity and correctness of spoken words |
| Contextual Appropriateness | Suitability for a professional meeting context |

No human reference audio was used. The evaluation was based on direct listening to the two TTS samples.

## Evaluation Results

| Criterion | Audio A | Audio B |
|---|---|---|
| Audio Quality | To be scored | To be scored |
| Naturalness | Good | Good |
| Pronunciation | Clear and correct | Clear and correct |
| Contextual Appropriateness | Appropriate | Appropriate |

## Observations

- Both audio samples sounded good and natural.
- Pronunciation was clear and correct in both samples.
- Both samples were appropriate for the professional meeting context.
- No clear overall preference emerged between the two samples based on the listening assessment.

## Conclusion

Based on the listening assessment, both TTS samples performed similarly across the observed criteria. Neither sample was clearly preferred overall.

This project demonstrates a structured approach to AI-generated speech evaluation, including criterion-based listening, comparative assessment, and evidence-based reporting.
